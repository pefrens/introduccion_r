¿Qué es la Ciencia de Datos?

  • Ciencia de datos es convertir datos brutos en conocimiento y comprensión

El Ciclo de la Ciencia de Datos

¿Por qué R?

R es Poderoso y Popular

  • Gratuito y de código abierto
  • Más de 20,000 paquetes disponibles
  • Comunidad activa y solidaria
  • Excelente para visualización (ggplot2)
  • Reproducibilidad con RMarkdown/Quarto
  • Integración con datos espaciales (sf, terra)

R + RStudio

El Ecosistema Tidyverse

Una colección de paquetes para ciencia de datos

Sesión 3: dplyr - Manipulación de Datos

Los verbos principales de dplyr:

  • select(): Seleccionar columnas
  • filter(): Filtrar filas
  • mutate(): Crear/modificar variables
  • summarise(): Resumir datos
  • group_by(): Agrupar datos
  • arrange(): Ordenar datos

Sesión 4: tidyr - Organización de Datos

  • Principios de Tidy Data
  • pivot_longer(): Datos anchos → largos
  • pivot_wider(): Datos largos → anchos
  • separate() y unite(): Dividir y unir columnas
  • Aplicaciones prácticas

Sesión 5: Datos Espaciales con sf

  • ¿Qué son datos espaciales?
  • El paquete sf (Simple Features)
  • Tipos de geometrías (puntos, líneas, polígonos)
  • Lectura/escritura de formatos espaciales
  • Integración con tidyverse
  • Visualización con geom_sf()
  • Operaciones espaciales básicas

Ejemplo de Datos Espaciales

# Cargar paquetes
library(sf)
library(tidyverse)

# Leer datos espaciales
departamentos <- read_sf("data/DEPARTAMENTO.gpkg")

# Visualizar
ggplot(departamentos) +
  geom_sf(aes(fill = NOMBDEP))

# Calcular área
departamentos |>
  mutate(area_km2 = st_area(geometry) / 1e6)

Preparación

Programas Necesarios

Asegúrate de tener instalados:

  1. R (versión 4.5.2 o superior)
    • cran.r-project.org
  2. RStudio (versión 1.1.401 o superior)
    • posit.co/download/rstudio-desktop
  3. Rtools 45 (solo Windows)
    • cran.r-project.org/bin/windows/Rtools

Paquetes Principales

# Tidyverse y manipulación de datos
packages <- c(
  "tidyverse",  # Colección completa
  "janitor",    # Limpieza de nombres
  "here",       # Rutas reproducibles
  "readxl",     # Leer Excel
  "writexl",    # Escribir Excel
  "visdat"      # Visualizar datos
)

install.packages(packages)

Paquetes Espaciales

# Paquetes para datos espaciales
spatial_packages <- c(
  "sf",        # Simple Features (principal)
  "terra",     # Datos ráster
  "mapview",   # Visualización interactiva
  "leaflet",   # Mapas web
  "tmap"       # Mapas temáticos
)

install.packages(spatial_packages)

Paquetes Adicionales

# Paquetes de texto
install.packages("tm")

# stringr.plus (desde GitHub)
install.packages("remotes")
remotes::install_github("johncassil/stringr.plus")

Recursos de Ayuda

  • Durante el curso: Pregunta directamente
  • Documentación de R: ?funcion o help(funcion)
  • Hojas de referencia: posit.co/resources/cheatsheets
  • Stack Overflow: stackoverflow.com/questions/tagged/r
  • RStudio Community: community.rstudio.com

Consejos para el Éxito

  1. Escribe el código tú mismo - no copies y pegues
  2. Lee los mensajes de error - son informativos
  3. Usa RStudio Projects - mantén organizado
  4. Comenta tu código - tu yo futuro te lo agradecerá
  5. Practica regularmente - la constancia es clave
  6. Únete a la comunidad - #rstats en Twitter
