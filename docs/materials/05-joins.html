Introducción

El análisis real involucra múltiples tablas

  • Rara vez trabajas con un solo data frame
  • Típicamente tienes muchos data frames
  • Necesitas unirlos para responder preguntas
  • Las relaciones entre tablas son clave

Tipos de joins

Dos categorías principales:

  1. Mutating joins: agregan nuevas variables desde otra tabla
    • Agregan columnas
  2. Filtering joins: filtran observaciones basándose en otra tabla
    • Afectan filas, no agregan columnas

Claves (Keys)

¿Qué es una clave?

  • Las claves conectan dos tablas
  • Dos tipos de claves:
    • Clave primaria (primary key)
    • Clave foránea (foreign key)

Clave foránea

Foreign key = variable(s) que corresponden a una clave primaria en otra tabla

Ejemplos modelo UBIGEO:

  • provincias$ccdd → departamentos$ccdd
  • distrito$ccdd → provincias$ccdd
  • distrito$ccpp → provincias$ccpp

Relaciones entre tablas

Tip

Claves primarias y foráneas casi siempre tienen el mismo nombre

Verificar claves primarias

Siempre verifica que las claves sean únicas:

departamentos |>
  count(ccdd) |>
  filter(n > 1)
# A tibble: 0 × 2
# ℹ 2 variables: ccdd <chr>, n <int>

Tip

0 filas = Perfecto! Cada ccdd es único

Verificar valores faltantes

Las claves no deben tener NA:

departamentos |>
  filter(is.na(ccdd))
# A tibble: 0 × 2
# ℹ 2 variables: ccdd <chr>, nombdep <chr>
provincias |>
  filter(is.na(ccdd) | is.na(ccpp))
# A tibble: 0 × 3
# ℹ 3 variables: ccdd <chr>, ccpp <chr>, nombprov <chr>

Note

0 filas = Bien! No hay NAs en las claves

Mutating Joins

¿Qué son los mutating joins?

  • Combinan variables de dos data frames (tibble)
  • Primero: encuentran observaciones coincidentes por claves
  • Segundo: copian variables de una tabla a otra
  • Como mutate(): agregan variables a la derecha

left_join(): El join más común

Otros mutating joins

Join Filas mantenidas
left_join(x, y) Todas de x
right_join(x, y) Todas de y
inner_join(x, y) Solo coincidencias (en x Y y)
full_join(x, y) Todas (x O y)

Tip

left_join() es el más usado (≈95% del tiempo)

Filtering Joins

¿Qué son filtering joins?

  • No agregan columnas
  • Filtran filas basándose en coincidencias
  • Dos tipos:
    • semi_join(): mantiene coincidencias
    • anti_join(): elimina coincidencias

¿Cómo funcionan los joins?

Tablas de ejemplo

Tablas simples para entender la mecánica:

x <- tribble(
  ~key, ~val_x,
     1, "x1",
     2, "x2",
     3, "x3"
)

y <- tribble(
  ~key, ~val_y,
     1, "y1",
     2, "y2",
     4, "y3"
)

Visualización de potenciales coincidencias

  • Cada línea horizontal = fila de x
  • Cada línea vertical = fila de y
  • Intersecciones = coincidencias potenciales

inner_join()

x |> inner_join(y, join_by(key))
# A tibble: 2 × 3
    key val_x val_y
  <dbl> <chr> <chr>
1     1 x1    y1   
2     2 x2    y2

Note

Solo filas donde las claves coinciden en ambas tablas

left_join()

x |> left_join(y, join_by(key))
# A tibble: 3 × 3
    key val_x val_y
  <dbl> <chr> <chr>
1     1 x1    y1   
2     2 x2    y2   
3     3 x3    <NA>

Note

Todas las filas de x, con NA si no hay coincidencia

Coincidencias múltiples

¿Qué pasa si una fila coincide con múltiples filas?

df1 <- tibble(key = c(1, 2, 2), val_x = c("x1", "x2", "x3"))
df2 <- tibble(key = c(1, 2, 2), val_y = c("y1", "y2", "y3"))
df1 |> inner_join(df2, join_by(key))
# A tibble: 5 × 3
    key val_x val_y
  <dbl> <chr> <chr>
1     1 x1    y1   
2     2 x2    y2   
3     2 x2    y3   
4     2 x3    y2   
5     2 x3    y3

Explosión combinatoria

Cuidado con many-to-many

  • La fila 2 de df1 coincide con 2 filas de df2
  • La fila 3 de df1 coincide con 2 filas de df2
  • Resultado: 2 × 2 = 4 filas para key = 2

Si es intencional:

df1 |>
  inner_join(df2, join_by(key), relationship = "many-to-many")
# A tibble: 5 × 3
    key val_x val_y
  <dbl> <chr> <chr>
1     1 x1    y1   
2     2 x2    y2   
3     2 x2    y3   
4     2 x3    y2   
5     2 x3    y3

Non-Equi Joins

Más allá de la igualdad

Hasta ahora: equi joins (claves son iguales)

Ahora: otras formas de coincidencia

  • Cross joins: todas las combinaciones
  • Inequality joins: <, <=, >, >=
  • Rolling joins: coincidencia más cercana
  • Overlap joins: rangos que se superponen

Mostrar ambas claves

Con keep = TRUE:

x |> inner_join(y, join_by(key == key), keep = TRUE)
# A tibble: 2 × 4
  key.x val_x key.y val_y
  <dbl> <chr> <dbl> <chr>
1     1 x1        1 y1   
2     2 x2        2 y2

Note

En equi joins, key.x == key.y siempre. En non-equi joins, pueden diferir.

Coincidencia más cercana en lugar de todas:

Overlap joins

Ayudantes para trabajar con intervalos:

  • between(x, y_lower, y_upper)
    • Equivale a: x >= y_lower, x <= y_upper
  • within(x_lower, x_upper, y_lower, y_upper)
    • Equivale a: x_lower >= y_lower, x_upper <= y_upper
  • overlaps(x_lower, x_upper, y_lower, y_upper)
    • Equivale a: x_lower <= y_upper, x_upper >= y_lower

Ejemplo: Periodos de fiestas

parties <- tibble(
  q = 1:4,
  party = ymd(c("2022-01-10", "2022-04-04", "2022-07-11", "2022-10-03")),
  start = ymd(c("2022-01-01", "2022-04-04", "2022-07-11", "2022-10-03")),
  end = ymd(c("2022-04-03", "2022-07-10", "2022-10-02", "2022-12-31"))
)
employees |>
  inner_join(parties, join_by(between(birthday, start, end)))

Detectar superposiciones

  inner_join(parties, join_by(overlaps(start, end, start, end), q < q)) |>
  select(start.x, end.x, start.y, end.y)

Resumen

Conceptos clave

  • Claves primarias: identifican observaciones únicamente
  • Claves foráneas: conectan con claves primarias en otras tablas
  • Mutating joins: agregan columnas (left, right, inner, full)
  • Filtering joins: filtran filas (semi, anti)
  • Non-equi joins: más allá de la igualdad (cross, inequality, rolling, overlap)

Funciones de joins

Función Tipo Filas resultantes
left_join() Mutating Todas de x
right_join() Mutating Todas de y
inner_join() Mutating Solo coincidencias
full_join() Mutating Todas de x o y
semi_join() Filtering x que coinciden en y
anti_join() Filtering x que NO coinciden en y

join_by() y sus usos

# Equi join
join_by(key)
Join By:
- key
join_by(key == key)
Join By:
- key == key
# Diferentes nombres
join_by(dest == faa)
Join By:
- dest == faa
# Inequality
join_by(key >= key)
Join By:
- key >= key
# Rolling
join_by(closest(birthday >= party))
Join By:
- closest(birthday >= party)
# Overlap
join_by(between(x, lower, upper))
Join By:
- between(x, lower, upper)
join_by(overlaps(x_lo, x_hi, y_lo, y_hi))
Join By:
- overlaps(x_lo, x_hi, y_lo, y_hi)

Consejos importantes

  1. Usa left_join() en el 95% de los casos
  2. Especifica claves explícitamente con join_by()
  3. Verifica duplicados antes de unir
  4. Cuidado con many-to-many (puede explotar filas)
  5. Usa keep = TRUE cuando necesites ver ambas claves
  6. anti_join() es perfecto para encontrar valores faltantes

Errores comunes

Error Solución
Unir por todas las variables comunes Especifica join_by() explícitamente
Sufijos confusos (.x, .y) Cambia con argumento suffix
Many-to-many warning Investiga duplicados, usa relationship = "many-to-many" si es intencional
NAs inesperados Usa anti_join() para encontrar qué no coincide
Demasiadas filas Revisa coincidencias múltiples
