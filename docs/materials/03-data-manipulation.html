Introducción a dplyr

¿Qué es dplyr?

  • Paquete del tidyverse para manipulación de datos
  • Proporciona verbos (funciones) para operaciones comunes
  • Diseñado para ser intuitivo y consistente
  • Funciona con tibbles y data frames

Los verbos de dplyr

Verbo Acción
filter() Selecciona filas según condiciones
arrange() Ordena filas
distinct() Encuentra filas únicas
mutate() Crea o modifica columnas
select() Selecciona columnas
summarise() Resume datos (colapsa filas)
group_by() Agrupa datos para operaciones

Estructura común

Todos los verbos de dplyr funcionan de manera similar:

  1. Primer argumento: un data frame
  2. Argumentos siguientes: qué hacer con el data frame
  3. Nombres de variables: sin comillas
  4. Resultado: un nuevo data frame (no modifica el original)
# Estructura general
verbo(datos, operacion)

Cargar paquetes

library(tidyverse)
library(readxl)

# Cargar datos de áreas naturales
anp <- read_excel("data/areas_naturales_peru.xlsx")

Operaciones con filas

filter() - Filtrar filas

Selecciona filas que cumplen una o más condiciones:

# Áreas naturales de categoría "Parque Nacional"
filter(anp, categoria == "Parque Nacional")
# Áreas con superficie mayor a 100,000 hectáreas
filter(anp, superficie_oficial > 100000)

Operadores de comparación

Operador Significado
> mayor que
>= mayor o igual que
< menor que
<= menor o igual que
== igual a
!= diferente de

¡Cuidado!

Usa == para comparar, no =

Operadores lógicos

Combinar múltiples condiciones:

Operador Significado
& Y (ambas condiciones verdaderas)
| O (al menos una condición verdadera)
! NO (negación) 
# Parques Nacionales con más de 100,000 ha
filter(anp, categoria == "Parque Nacional" & superficie_oficial > 100000)
# Áreas en Cusco o Loreto
filter(anp, ubicacion_politica == "Cusco" | ubicacion_politica == "Loreto")

Operador %in%

Para comparar con múltiples valores:

# Áreas en varios departamentos (forma larga)
filter(anp,
       ubicacion_politica == "Cusco" |
       ubicacion_politica == "Loreto" |
       ubicacion_politica == "Madre de Dios")
# Forma más elegante con %in%
departamentos <- c("Cusco", "Loreto", "Madre de Dios")
filter(anp, ubicacion_politica %in% departamentos)

Valores faltantes (NA)

# is.na() identifica valores faltantes
filter(anp, is.na(superficie_oficial))
# !is.na() identifica valores NO faltantes
filter(anp, !is.na(superficie_oficial))

Recuerda

NA representa la ausencia de un valor. No uses == NA, usa is.na()

arrange() - Ordenar filas

Ordena filas según una o más columnas:

# Ordenar por superficie (de menor a mayor)
arrange(anp, superficie_oficial)
# Ordenar de mayor a menor con desc()
arrange(anp, desc(superficie_oficial))

Ordenar por múltiples columnas

# Primero por categoría, luego por superficie
arrange(anp, categoria, desc(superficie_oficial))

Note

Los valores NA siempre se colocan al final, sin importar si usas desc() o no

distinct() - Filas únicas

Encuentra filas únicas (elimina duplicados):

# Categorías únicas de áreas naturales
distinct(anp, categoria)
# Mantener todas las columnas
distinct(anp, categoria, .keep_all = TRUE)

distinct() vs count()

# distinct() muestra valores únicos
distinct(anp, categoria)
# count() cuenta las ocurrencias
count(anp, categoria)
# Ordenar por frecuencia
count(anp, categoria, sort = TRUE)

Operaciones con columnas

mutate() - Crear/modificar columnas

Crea nuevas columnas o modifica existentes:

# Convertir superficie de hectáreas a km²
mutate(anp, superficie_km2 = superficie_oficial / 100)
# Crear múltiples columnas
mutate(anp,
  superficie_km2 = superficie_oficial / 100,
  area_grande = superficie_oficial > 100000
)

Operaciones con mutate()

Puedes usar operadores aritméticos:

mutate(anp,
  # Operaciones aritméticas
  superficie_acres = superficie_oficial * 2.47105,
  # Operaciones lógicas
  es_parque = str_detect(categoria, "Parque"),
  # Funciones
  nombre_mayus = str_to_upper(nombre)
)

Opciones de mutate()

  • .before - colocar nuevas columnas antes de otra columna
  • .after - colocar nuevas columnas después de otra columna
  • .keep - qué columnas mantener
# Colocar nueva columna al inicio
mutate(anp,
  superficie_km2 = superficie_oficial / 100,
  .before = 1
)
# Mantener solo columnas nuevas
mutate(anp,
  superficie_km2 = superficie_oficial / 100,
  .keep = "none"
)

select() - Seleccionar columnas

Selecciona columnas por nombre:

# Seleccionar columnas específicas
select(anp, nombre, categoria, superficie_oficial)
# Seleccionar rango de columnas
select(anp, nombre:ubicacion_politica)
# Excluir columnas con -
select(anp, -fecha_promulgacion__modificacion)

Funciones auxiliares de select()

Función Uso
starts_with("abc") Columnas que empiezan con “abc”
ends_with("xyz") Columnas que terminan con “xyz”
contains("ijk") Columnas que contienen “ijk”
num_range("x", 1:3) Columnas x1, x2, x3
everything() Todas las columnas
where(is.numeric) Columnas que cumplen una condición

Ejemplos de funciones auxiliares

# Columnas que empiezan con "superficie"
select(anp, starts_with("superficie"))
# Columnas numéricas
select(anp, where(is.numeric))
# Reorganizar: nombre primero, luego todo lo demás
select(anp, nombre, everything())

rename() - Renombrar columnas

# Sintaxis: nuevo_nombre = nombre_antiguo
rename(anp,
  area = nombre,
  departamento = ubicacion_politica
)

Atajo

También puedes renombrar con select():

select(anp, area = nombre, categoria)

relocate() - Reordenar columnas

Cambia la posición de columnas:

# Mover columna al inicio
relocate(anp, superficie_oficial)
# Mover después de otra columna
relocate(anp, superficie_oficial, .after = nombre)
# Mover antes de otra columna
relocate(anp, superficie_oficial, .before = categoria)

El operador pipe

El pipe |>

El pipe (tubería) te permite encadenar operaciones:

  • Lee el código de izquierda a derecha
  • Pasa el resultado de una función a la siguiente
  • Hace el código más legible
  • Atajo de teclado: Ctrl + Shift + M (Windows) o Cmd + Shift + M (Mac)

Sin pipe vs con pipe

Sin pipe (anidado y difícil de leer):

arrange(
  filter(
    select(anp, nombre, categoria, superficie_oficial),
    categoria == "Parque Nacional"
  ),
  desc(superficie_oficial)
)

Con pipe (fluido y claro):

anp |>
  select(nombre, categoria, superficie_oficial) |>
  filter(categoria == "Parque Nacional") |>
  arrange(desc(superficie_oficial))

Ventajas del pipe

  1. Legibilidad: Se lee como una receta paso a paso
  2. Menos objetos intermedios: No necesitas guardar resultados temporales
  3. Fácil modificar: Agregar o quitar pasos es simple
  4. Debugging más fácil: Puedes ejecutar el código línea por línea

Dos tipos de pipe

  • |> - pipe nativo de R (desde R 4.1)
  • %>% - pipe de magrittr (del tidyverse)

Ambos funcionan igual en la mayoría de casos. Usaremos |> en este curso.

Ejemplo completo con pipe

anp |>
  # Seleccionar columnas relevantes
  select(nombre, categoria, superficie_oficial, ubicacion_politica) |>
  # Filtrar Parques Nacionales
  filter(categoria == "Parque Nacional") |>
  # Crear nueva columna
  mutate(superficie_km2 = superficie_oficial / 100) |>
  # Ordenar por superficie
  arrange(desc(superficie_km2))

Operaciones agrupadas

group_by() - Agrupar datos

Agrupa filas para aplicar operaciones por grupo:

anp |>
  group_by(categoria)

Note

group_by() no cambia los datos visualmente, pero afecta cómo funcionan otros verbos

summarise() - Resumir datos

Colapsa filas en resúmenes estadísticos:

anp |>
  group_by(categoria) |>
  summarise(
    n_areas = n(),
    superficie_promedio = mean(superficie_oficial, na.rm = TRUE)
  )
  • n() cuenta el número de filas en cada grupo
  • Puedes usar cualquier función de resumen: mean(), median(), sd(), min(), max(), sum()
  • na.rm = TRUE ignora valores faltantes

Múltiples resúmenes

anp |>
  group_by(categoria) |>
  summarise(
    cantidad = n(),
    sup_total = sum(superficie_oficial, na.rm = TRUE),
    sup_promedio = mean(superficie_oficial, na.rm = TRUE),
    sup_min = min(superficie_oficial, na.rm = TRUE),
    sup_max = max(superficie_oficial, na.rm = TRUE)
  )

Funciones de slice

Seleccionan filas específicas dentro de grupos:

Función Acción
slice_head(n = 1) Primera(s) fila(s)
slice_tail(n = 1) Última(s) fila(s)
slice_min(columna, n = 1) Fila(s) con valor mínimo
slice_max(columna, n = 1) Fila(s) con valor máximo
slice_sample(n = 1) Fila(s) aleatoria(s)

Ejemplos de slice

# El área más grande de cada categoría
anp |>
  group_by(categoria) |>
  slice_max(superficie_oficial, n = 1)
# Las 3 áreas más grandes en total
anp |>
  slice_max(superficie_oficial, n = 3)

Múltiples variables de agrupación

# Agrupar por categoría y departamento
anp |>
  group_by(categoria, ubicacion_politica) |>
  summarise(
    cantidad = n(),
    superficie_total = sum(superficie_oficial, na.rm = TRUE)
  )

Desagrupar

Después de summarise(), se elimina el último nivel de agrupación. Usa ungroup() para eliminar todos los niveles.

El argumento .by

Nueva forma de agrupar (dplyr 1.1.0+):

# Forma tradicional
anp |>
  group_by(categoria) |>
  summarise(cantidad = n())
# Con .by (más conciso)
anp |>
  summarise(
    cantidad = n(),
    .by = categoria
  )

Tip

Con .by no necesitas ungroup() al final

Ejercicios prácticos

Ejercicio 1

Con los datos de áreas naturales protegidas:

  1. Filtra las áreas con superficie mayor a 50,000 hectáreas
  2. Selecciona las columnas: nombre, categoría, superficie_oficial
  3. Ordena por superficie de mayor a menor
  4. ¿Cuál es el área más grande?

Usa el pipe |> para encadenar las operaciones.

Ejercicio 2

Responde las siguientes preguntas usando group_by() y summarise():

  1. ¿Cuántas áreas naturales hay por categoría?
  2. ¿Cuál es la superficie total protegida por categoría?
  3. ¿Cuál categoría tiene la mayor superficie promedio?

Pista: Usa arrange(desc(...)) al final para ordenar los resultados.

Ejercicio 3

Crea un nuevo data frame que:

  1. Contenga solo Parques Nacionales y Reservas Nacionales
  2. Agregue una columna que clasifique las áreas como “Grande” (>100,000 ha) o “Mediana” (≤100,000 ha)
  3. Cuente cuántas áreas hay de cada tamaño en cada categoría

Pista: Usa if_else() dentro de mutate():

mutate(tamaño = if_else(superficie_oficial > 100000, "Grande", "Mediana"))

Ejercicio 4

Para cada departamento (ubicacion_politica):

  1. Encuentra el área natural más grande
  2. Muestra solo: departamento, nombre del área, superficie
  3. Ordena por superficie de mayor a menor

Pista: Usa slice_max() después de agrupar.

Recapitulación

Resumen de verbos dplyr

Operaciones con filas:

  • filter() - seleccionar filas por condición
  • arrange() - ordenar filas
  • distinct() - encontrar filas únicas

Operaciones con columnas:

  • mutate() - crear/modificar columnas
  • select() - seleccionar columnas
  • rename() - renombrar columnas
  • relocate() - reordenar columnas

Operaciones agrupadas:

  • group_by() - agrupar datos
  • summarise() - resumir datos
  • slice_*() - seleccionar filas específicas

Consejos finales

  1. Usa el pipe |> para encadenar operaciones y hacer tu código más legible

  2. Los verbos no modifican los datos originales - siempre crean nuevos data frames

  3. Guarda los resultados si los necesitas después:

    anp_parques <- anp |> filter(categoria == "Parque Nacional")

  4. Combina verbos para análisis complejos

  5. Usa View() o glimpse() para inspeccionar resultados intermedios
