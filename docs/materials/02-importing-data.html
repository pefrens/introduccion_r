Lectura de Datos desde Archivos

Introducción

  • Trabajar con datos de paquetes R es útil para aprender
  • Pero eventualmente querrás usar tus propios datos
  • Nos enfocaremos en archivos de texto rectangulares
  • El formato más común: CSV (Comma-Separated Values)

¿Qué es un Archivo CSV?

Un archivo de texto donde:

  • Cada línea es una fila
  • Los valores están separados por comas
  • La primera línea generalmente contiene los nombres de columnas
Student ID,Full Name,favourite.food,mealPlan,AGE
1,Sunil Huffmann,Strawberry yoghurt,Lunch only,4
2,Barclay Lynn,French fries,Lunch only,5
3,Jayendra Lyne,N/A,Breakfast and lunch,7

Anatomía de un CSV

Archivo de texto:

pais,año,poblacion
Peru,2020,32971846
Peru,2021,33359416
Chile,2020,19116209
Chile,2021,19212362

Como tabla:

pais año poblacion
Peru 2020 32971846
Peru 2021 33359416
Chile 2020 19116209
Chile 2021 19212362

Usando read_csv()

Configuración

Primero, cargar el paquete tidyverse:

library(tidyverse)

El paquete readr (parte de tidyverse) proporciona funciones para leer datos.

Leer un Archivo CSV

# Sintaxis básica
datos <- read_csv("ruta/al/archivo.csv")

# Ejemplo con datos de estudiantes
students <- read_csv("data/students.csv")

read_csv() imprime información útil:

  • Número de filas y columnas
  • Delimitador usado
  • Especificación de columnas (tipos de datos)

Mensaje de read_csv()

chr (4): Full Name, favourite.food, mealPlan, AGE
dbl (1): Student ID

ℹ Use `spec()` to retrieve the full column specification
ℹ Specify column types or set `show_col_types = FALSE`

Note

Este mensaje es importante y útil. Te dice cómo interpretó readr tu archivo.

Rutas de Archivos

Dos formas de especificar la ubicación del archivo:

# 1. Ruta relativa (dentro de tu proyecto)
students <- read_csv("data/students.csv")

# 2. URL directa
students <- read_csv("https://pos.it/r4ds-students-csv")

Tip

Las rutas relativas son más reproducibles. Usa RStudio Projects para organizarte.

Problemas Comunes: Valores Faltantes

¿Ves algún problema en los datos de estudiantes?

  • Fila 3: favourite.food tiene "N/A" (texto) en lugar de NA (valor faltante)
  • Fila 5: AGE tiene "five" (texto) en lugar de 5 (número)

Solución: Argumento na

Especifica qué cadenas deben interpretarse como valores faltantes:

students <- read_csv(
  "data/students.csv",
  na = c("N/A", "")  # Reconocer "N/A" y "" como NA
)

Ahora favourite.food tiene un verdadero NA:

3            3 Jayendra Lyne    <NA>               Breakfast and lunch 7

Problemas Comunes: Nombres de Columnas

Los nombres de columnas tienen espacios:

  • Student ID
  • Full Name

En R, estos son nombres no sintácticos y necesitan backticks:

students$`Student ID`  # Necesita backticks
students$Student ID    # ❌ Error!

Solución 1: rename()

Renombrar manualmente con rename():

students |>
  rename(
    student_id = `Student ID`,
    full_name = `Full Name`
  )

Solución 2: janitor::clean_names()

La forma más fácil y recomendada:

library(janitor)

students |>
  clean_names()
# A tibble: 6 × 5
  student_id full_name        favourite_food     meal_plan           age
       <dbl> <chr>            <chr>              <chr>               <chr>
1          1 Sunil Huffmann   Strawberry yoghurt Lunch only          4
2          2 Barclay Lynn     French fries       Lunch only          5

Tip

clean_names() convierte todos los nombres a snake_case automáticamente.

Problemas Comunes: Tipos de Datos

La columna AGE es character (<chr>) pero debería ser numérica:

students |>
  clean_names() |>
  glimpse()
$ age           <chr> "4", "5", "7", NA, "five", "6"

¿Por qué AGE es character?

Porque tiene "five" (texto) mezclado con números.

Solución: Limpiar y Convertir

students <- students |>
  clean_names() |>
  mutate(
    age = parse_number(if_else(age == "five", "5", age))
  )

Qué hace este código:

  1. if_else(): Si age es "five", cámbialo a "5", si no déjalo igual
  2. parse_number(): Convierte texto a número

Variables Categóricas: Factores

meal_plan debería ser un factor (variable categórica):

students <- students |>
  clean_names() |>
  mutate(
    meal_plan = factor(meal_plan)
  )

Ahora meal_plan es <fct> en lugar de <chr>:

$ meal_plan     <fct> Lunch only, Lunch only, Breakfast and lunch

Pipeline Completo de Limpieza

students <- read_csv("data/students.csv", na = c("N/A", "")) |>
  clean_names() |>
  mutate(
    meal_plan = factor(meal_plan),
    age = parse_number(if_else(age == "five", "5", age))
  )

Trabajando con Hojas de Cálculo (Excel)

Introducción a Hojas de Cálculo

  • Microsoft Excel es ampliamente usado para organizar datos
  • Los datos se almacenan en hojas (worksheets) dentro de libros (workbooks)
  • Excel permite múltiples hojas en un solo archivo
  • Importante: Leer el artículo “Data Organization in Spreadsheets” (Broman & Woo, 2018)

Paquetes para Excel

Usaremos dos paquetes principales:

library(readxl)   # Para leer archivos Excel
library(writexl)  # Para escribir archivos Excel
library(tidyverse)

Note

readxl está incluido en tidyverse pero debe cargarse explícitamente

Funciones de readxl

Función Uso
read_xls() Lee archivos con formato .xls (Excel 97-2003)
read_xlsx() Lee archivos con formato .xlsx (Excel 2007+)
read_excel() Detecta automáticamente el formato

Tip

Usa read_excel() para no preocuparte por el formato

Ejemplo: Leer Archivo Excel

library(readxl)

students <- read_excel("data/students.xlsx")
students
# A tibble: 6 × 5

2            2 Barclay Lynn     French fries       Lunch only          5

Problemas con Excel

Similar a CSV, necesitamos limpiar:

  1. Nombres de columnas con espacios
  2. Valores faltantes no reconocidos ("N/A")
  3. Tipos de datos incorrectos
students <- read_excel("data/students.xlsx", na = c("", "N/A"))

Limpiar Nombres de Columnas

students <- read_excel(
  "data/students.xlsx",
  col_names = c("student_id", "full_name", "favourite_food",
                "meal_plan", "age"),
  skip = 1  # Saltar fila de encabezados originales
)

Tip

O usa janitor::clean_names() después de importar

Especificar Tipos en Excel

Excel usa diferentes tipos que R:

students <- read_excel(
  "data/students.xlsx",
  col_types = c("numeric", "text", "text", "text", "text")
)

Opciones para col_types:

  • "skip" - saltar columna
  • "guess" - adivinar tipo
  • "logical" - booleano
  • "numeric" - numérico
  • "date" - fecha
  • "text" - texto
  • "list" - lista (mezcla de tipos)

Notación de celdas en Excel: A1 = primera celda (columna A, fila 1)

Tipos de Datos en Excel

Excel almacena datos internamente diferente a como los muestra:

  • Booleanos: TRUE, FALSE, NA
  • Números: Todos son decimales (no hay enteros)
  • Fechas: Almacenadas como número de días desde 1900-01-01
  • Texto: Cadenas de caracteres

Cuidado

Lo que ves en Excel puede no ser lo que está almacenado. Por ejemplo, “10” podría ser número o texto.

Consejos para Hojas de Cálculo

  1. Siempre mira el archivo primero en Excel (hacer copia)
  2. Proceso iterativo: importa → revisa → ajusta → reimporta
  3. Especifica na explícitamente
  4. Usa range si hay texto extra arriba/abajo
  5. No confíes en el formato visual - verifica tipos
  6. Para archivos complejos: considera tidyxl package

Importar Datos Espaciales

Introducción a Datos Espaciales

  • Datos geográficos representan ubicaciones en la superficie terrestre
  • Dos modelos principales: vectorial y ráster
  • Vector: puntos, líneas, polígonos (ubicaciones discretas)
  • Ráster: celdas/píxeles en una cuadrícula (fenómenos continuos)

Paquete sf para Datos Vectoriales

library(sf)  # Simple Features for R

sf proporciona:

  • Clases para datos geográficos vectoriales
  • Interfaz a GDAL (lectura/escritura de formatos)
  • Interfaz a GEOS (operaciones geométricas)
  • Interfaz a PROJ (sistemas de coordenadas)
  • Compatible con tidyverse

Sistemas de Coordenadas (CRS)

Dos tipos principales:

Geográficas (lon/lat)

  • Grados de longitud/latitud
  • Ejemplo: WGS84 (GPS)
  • EPSG:4326

Proyectadas (x/y)

  • Metros o pies
  • Superficie plana
  • Ejemplo: UTM
  • Mejor para cálculos

Leer Datos Espaciales

# Leer shapefile, geopackage, geojson, etc.
departamentos <- read_sf("data/DEPARTAMENTO.gpkg")

# Alternativa más verbosa
departamentos <- st_read("data/DEPARTAMENTO.gpkg")

Estructura de Objetos sf

sf es un data frame especial

  • Columnas normales para atributos
  • Columna especial geometry o geom para geometría
  • Funciona con dplyr, ggplot2, etc.

Explorar Datos Espaciales

glimpse(departamentos)

# Ver primeras filas
head(departamentos)

st_crs(departamentos)

departamentos <- departamentos |>
  mutate(area_km2 = st_area(geometry) |>

Visualizar Datos Espaciales

# Mapa básico con plot()
plot(departamentos["NOMBDEP"])

# Con ggplot2
ggplot(departamentos) +
  geom_sf(aes(fill = NOMBDEP)) +
  theme_minimal()

Operaciones Espaciales Básicas

# Filtrar (funciona como data frame normal)
lima <- departamentos |>
  filter(NOMBDEP == "LIMA")

# Transformar CRS (proyectar)
departamentos_utm <- departamentos |>
  st_transform(crs = "EPSG:32718")  # UTM Zone 18S

# Centroides
centroides <- st_centroid(departamentos)

# Buffer (zona de influencia)
buffer_lima <- st_buffer(lima, dist = 50000)  # 50 km

Escribir Datos Espaciales

# Guardar como GeoPackage (recomendado)
write_sf(departamentos, "data/departamentos_procesado.gpkg")

# Guardar como shapefile
write_sf(departamentos, "data/departamentos.shp")

# Guardar como GeoJSON
write_sf(departamentos, "data/departamentos.geojson")

Integración con tidyverse

# sf funciona perfectamente con dplyr
departamentos_resumen <- departamentos |>
  mutate(area_km2 = as.numeric(st_area(geometry) / 1e6)) |>
  select(NOMBDEP, CAPITAL, area_km2) |>
  arrange(desc(area_km2))

# La columna geometry es "sticky" - se mantiene automáticamente

Formatos Espaciales Comunes

Formato Extensión Características

Shapefile .shp Legacy, múltiples archivos
GeoJSON .geojson Formato web, legible

Tip

Recomendación: Usa GeoPackage (.gpkg) para proyectos nuevos

Ejemplo Completo: Workflow Espacial

library(sf)
library(tidyverse)

# 1. Leer datos espaciales
departamentos <- read_sf("data/DEPARTAMENTO.gpkg")

# 2. Limpiar y transformar
departamentos_clean <- departamentos |>
  clean_names() |>
  select(nombre = nombdep, capital, region = nombdistri) |>
  st_transform(crs = "EPSG:32718")  # Proyectar a UTM

# 3. Calcular métricas espaciales
departamentos_metrics <- departamentos_clean |>
  mutate(
    area_km2 = as.numeric(st_area(geometry) / 1e6),
    perimetro_km = as.numeric(st_length(st_cast(geometry, "MULTILINESTRING")) / 1000)
  )

# 4. Guardar resultado
write_sf(departamentos_metrics, "output/departamentos_procesado.gpkg")

Controlando Tipos de Columnas

Adivinanza de Tipos

readr intenta adivinar el tipo de cada columna:

  1. ¿Solo TRUE/FALSE? → lógico
  2. ¿Solo números? → numérico
  3. ¿Cumple estándar ISO8601? → fecha/fecha-hora
  4. Si no → character

readr revisa las primeras 1,000 filas para decidir.

Ejemplo de Adivinanza

read_csv(
  "logical,numeric,date,string
   TRUE,1,2021-01-15,abc
   false,4.5,2021-02-15,def
   T,Inf,2021-02-16,ghi"
)
# A tibble: 3 × 4
  logical numeric date       string
  <lgl>     <dbl> <date>     <chr> 
1 TRUE        1   2021-01-15 abc   
2 FALSE       4.5 2021-02-15 def   
3 TRUE      Inf   2021-02-16 ghi

Cuando Falla la Adivinanza

Problema común: valores inesperados causan que la columna sea character:

simple_csv <- "
  x
  10
  .
  20
  30"

read_csv(simple_csv)
# A tibble: 4 × 1
  x    
  <chr>
1 10   
2 .    
3 20   
4 30

x es character porque tiene un . (punto).

Solución: Especificar Tipo

df <- read_csv(
  simple_csv,
  col_types = list(x = col_double())
)

readr reporta un problema. Usa problems() para ver detalles:

problems(df)
# A tibble: 1 × 5
    row   col expected actual file
  <int> <int> <chr>    <chr>  <chr>
1     3     1 a double .      /tmp/...

Solución Final: Especificar NA

El problema es que . representa valores faltantes:

read_csv(simple_csv, na = ".")
# A tibble: 4 × 1
      x
  <dbl>
1    10
2    NA
3    20
4    30

Ahora x es numérico y . se convierte en NA.

Tipos de Columna Disponibles

Función Tipo
col_logical() Valores lógicos (TRUE/FALSE)
col_double() Números reales
col_integer() Números enteros
col_character() Texto/cadenas
col_factor() Factores (variables categóricas)
col_date() Fechas
col_datetime() Fecha-hora
col_number() Números con formato (ej. monedas)
col_skip() Saltar columna

Ejemplo: Especificar Tipos

another_csv <- "
x,y,z
1,2,3"

read_csv(

  col_types = cols(.default = col_character())
)

Guardar Datos

Escribir a CSV

# Guardar data frame como CSV
write_csv(students, "students-clean.csv")

Problema: Se pierden los tipos de datos (factores, etc.)

# meal_plan era factor, ahora es character
students_leido <- read_csv("students-clean.csv")

Solución 1: RDS (Formato R)

# Guardar en formato R
write_rds(students, "students.rds")

# Leer - mantiene todos los tipos
students <- read_rds("students.rds")

Tip

RDS preserva exactamente el objeto R, incluyendo tipos de datos.

Solución 2: Parquet (Recomendado)

library(arrow)

# Guardar en formato Parquet
write_parquet(students, "students.parquet")

# Leer
students <- read_parquet("students.parquet")

Tip

Parquet es más rápido que RDS y compatible con otros lenguajes.

Comparación de Formatos

Formato Velocidad Tipos preservados Compatible otros lenguajes
CSV Media ❌ No ✅ Sí
RDS Rápida ✅ Sí ❌ No (solo R)
Parquet Muy rápida ✅ Sí ✅ Sí (Python, etc.)

Entrada Manual de Datos

tibble(): Por Columnas

Crear data frames pequeños manualmente:

tibble(
  x = c(1, 2, 5),
  y = c("h", "m", "g"),
  z = c(0.08, 0.83, 0.60)
)
# A tibble: 3 × 3
      x y         z
  <dbl> <chr> <dbl>
1     1 h      0.08
2     2 m      0.83
3     5 g      0.6

tribble(): Por Filas

Más legible para entrada manual:

tribble(
  ~x, ~y, ~z,
  #--|--|----
  1,  "h", 0.08,
  2,  "m", 0.83,
  5,  "g", 0.60
)
# A tibble: 3 × 3
      x y         z
  <dbl> <chr> <dbl>
1     1 h      0.08
2     2 m      0.83
3     5 g      0.6

Tip

~ indica nombres de columnas. Las comas separan valores.

Flujo de Trabajo Típico

# 1. Importar
datos <- read_csv("ruta/archivo.csv", na = c("N/A", ""))

# 2. Limpiar nombres
datos <- datos |> clean_names()

# 3. Revisar
glimpse(datos)

# 4. Corregir tipos
datos <- datos |>
  mutate(
    categoria = factor(categoria),
    edad = parse_number(edad)
  )

# 5. Guardar limpio
write_rds(datos, "datos_limpios.rds")

Buenas Prácticas

  1. Siempre revisa los datos después de importar (glimpse(), head())
  2. Especifica valores NA explícitamente
  3. Limpia nombres inmediatamente con clean_names()

  5. Guarda versiones limpias en formatos que preserven tipos
  6. Usa rutas relativas dentro de proyectos

Errores Comunes y Soluciones

Error Solución
Archivo no encontrado Verifica ruta, usa RStudio Projects
Tipos incorrectos Usa col_types o limpia después
Valores NA no reconocidos Especifica con argumento na
Nombres con espacios Usa clean_names()
Encoding (acentos raros) Usa locale = locale(encoding = "UTF-8")
