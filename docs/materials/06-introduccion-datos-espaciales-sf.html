Modelo mental de sf

Jerarquia de objetos

  • sfg: una geometria individual (ej. un POINT)
  • sfc: una coleccion de geometrias con CRS
  • sf: data frame + columna geometry

Crear puntos desde coordenadas

ciudades <- tibble(
  ciudad = c("Lima", "Cusco", "Arequipa"),
  lon = c(-77.0428, -71.9675, -71.5350),
  lat = c(-12.0464, -13.5319, -16.4090)
)

ciudades_sf <- st_as_sf(ciudades, coords = c("lon", "lat"), crs = 4326)
ciudades_sf <- st_transform(ciudades_sf, st_crs(departamentos))

Operaciones espaciales

Join espacial: ciudades dentro de departamentos

ciudades_deptos <- st_join(
  ciudades_sf,
  departamentos |> select(ccdd, nombdep, geom),
  join = st_within,
  left = FALSE
)

Cierre

Ideas clave

  • sf integra geometrias y atributos en una sola estructura
  • Se manipula con verbos de dplyr casi igual que un tibble
  • Antes de medir, revisa y transforma el CRS
  • st_join() habilita analisis entre capas (punto, linea, poligono)

Proximos pasos
