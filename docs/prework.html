Requisitos Previos y Preparación

Este curso está diseñado para personas que desean aprender programación en R desde cero o que cuentan con nociones básicas y desean consolidar sus habilidades en el ecosistema Tidyverse y el manejo de datos espaciales con sf. No se requiere experiencia previa en programación, pero sí familiaridad elemental con el uso de datos en tablas u hojas de cálculo.

Para aprovechar al máximo las sesiones, recomendamos revisar el libro R for Data Science (versión en inglés o versión en español), especialmente los capítulos introductorios.

Necesitarás tu propia computadora portátil con una versión reciente de R (4.3.0 o superior) y RStudio Desktop (versión 2023 o más reciente), así como los paquetes indicados a continuación.

Requisitos Técnicos

1. Instalar R y RStudio

Descarga e instala los siguientes programas en este orden:

  1. R (versión 4.3.0 o superior): cloud.r-project.org
  2. RStudio Desktop (versión reciente): posit.co/download/rstudio-desktop/
  3. Rtools (solo para Windows): cran.r-project.org/bin/windows/Rtools/ (instala la versión compatible con tu versión de R).

2. Instalar Paquetes de R

Abre RStudio y pega el siguiente código en la consola (panel inferior izquierdo), luego presiona Enter:

# Paquetes principales y esenciales del curso
paquetes <- c(
  "tidyverse", # dlyr, tidyr, readr, ggplot2, tibble, etc.
  "janitor",   # Limpieza de nombres de variables y tablas
  "readxl",    # Lectura de archivos Excel (.xlsx, .xls)
  "writexl",   # Escritura y exportación a Excel
  "sf"         # Simple Features para análisis geoespacial vectorial
)

install.packages(paquetes)

Durante la instalación aparecerán varios mensajes informativos en la consola. Revisa que no existan mensajes de error (Error in...). Las advertencias (Warning) son normales y no impiden el funcionamiento.

3. Descripción de los Paquetes Principales

Ecosistema Tidyverse y Manipulación de Datos

  • tidyverse: Metapaquete que carga las herramientas estándar de la ciencia de datos en R:
    • readr: Lectura rápida de archivos de texto delimitados (CSV, TSV).
    • dplyr: Gramática para manipulación, filtrado, creación de variables y resúmenes.
    • tidyr: Herramientas para organizar tablas en formato ordenado (Tidy Data).
    • ggplot2: Creación de gráficos declarativos basados en la gramática de los gráficos.
  • janitor: Funciones prácticas para limpiar nombres de columnas (clean_names()) e identificar filas o columnas vacías.
  • readxl / writexl: Módulos especializados para interactuar con hojas de cálculo de Microsoft Excel sin dependencias externas.

Paquete Espacial

  • sf (Simple Features): Estándar moderno de R para el análisis de geometrías vectoriales (puntos, líneas y polígonos):
    • Integración total con la filosofía y funciones del Tidyverse.
    • Compatibilidad para leer y escribir GeoPackage (.gpkg), Shapefile (.shp) y GeoJSON.
    • Integración directa con ggplot2 mediante la capa geom_sf().

Paquetes Opcionales (Análisis Espacial Avanzado)

Si deseas explorar visualizaciones espaciales interactivas más adelante:

paquetes_espaciales_extra <- c("mapview", "leaflet", "tmap")
install.packages(paquetes_espaciales_extra)

Verificación del Entorno

Para confirmar que la instalación fue exitosa y que el motor espacial sf opera correctamente en tu equipo, ejecuta estas líneas en RStudio:

# 1. Verificar carga de paquetes esenciales
library(tidyverse)
library(janitor)
library(sf)

# 2. Comprobar funcionamiento básico de sf
punto_prueba <- st_point(c(-71.9675, -13.5319)) # Coordenadas aproximadas de Cusco
print(punto_prueba)

Si el comando imprime POINT (-71.9675 -13.5319) sin errores, ¡tu entorno está 100% listo para comenzar!
