dplyr - Manipulación de Datos

February 1, 2026

  • Los verbos de dplyr

  • mutate(): Crear/modificar variables
  • summarise() y group_by()

Los Verbos de dplyr

dplyr proporciona funciones (verbos) para manipular datos:

  • select(): Selecciona columnas
  • filter(): Filtra filas
  • mutate(): Crea o modifica variables
  • summarise(): Resume datos
  • group_by(): Agrupa datos
  • arrange(): Ordena datos

select() - Seleccionar Columnas

Por nombre

anp |>
  select(nombre_area)

anp |>
  select(nombre_area, categoria, extension_ha)

Por posición

anp |>
  select(1:3)

Con helpers

# Columnas que empiezan con...
anp |>
  select(starts_with("base"))

# Columnas que terminan con...
anp |>
  select(ends_with("cion"))

# Columnas que contienen...
anp |>
  select(contains("legal"))

filter() - Filtrar Filas

Igualdad

anp |>
  filter(codigo == "PN 01")

anp |>
  filter(nombre_area == "Huascarán")

Operadores

# Pertenece a
anp |>
  filter(codigo %in% c("PN 01", "PN 02", "PN 03"))

# No pertenece
anp |>
  filter(!codigo %in% c("PN 01", "PN 02", "PN 03"))

Detectar patrones

library(stringr)
anp |>
  filter(str_detect(nombre_area, "Alto"))

Múltiples condiciones

# Y (&)
anp |>
  filter(str_detect(nombre_area, "Alto") &
         extension_ha > 1000)

# O (|)
anp |>
  filter(str_detect(nombre_area, "Alto") |
         ubicacion_politica == "CUSCO")

mutate() - Crear/Modificar Variables

Operaciones matemáticas

anp |>
  mutate(extension_doble = extension_ha * 2)

Manipulación de texto

# Eliminar espacios
anp |>
  mutate(nombre_area = str_trim(nombre_area))

# Minúsculas
anp |>
  mutate(categoria = str_to_lower(categoria))

# Mayúsculas
anp |>
  mutate(nombre_area = str_to_upper(nombre_area))

# Título
anp |>
  mutate(ubicacion_politica = str_to_title(ubicacion_politica))

Limpiar texto

library(tm)

anp |>
  mutate(categoria_clean = removePunctuation(categoria) |>
           removeNumbers() |>
           str_squish())

summarise() y group_by()

Resúmenes simples

anp |>
  summarise(numero_categorias = n_distinct(categoria))

anp |>
  summarise(area_total = sum(extension_ha))

Resúmenes por grupo

anp |>
  group_by(categoria) |>
  summarise(numero_areas = n_distinct(nombre_area))

arrange() - Ordenar

# Ascendente
anp |>
  arrange(extension_ha)

# Descendente
anp |>
  arrange(desc(extension_ha))

Ejercicios

Ejercicio 1

  • Selecciona las columnas nombre_area, categoria y extension_ha
  • Filtra solo las áreas con extensión mayor a 10000 hectáreas
  • Ordena por extensión de mayor a menor

Ejercicio 2

  • Crea una nueva variable que indique si el área es grande (> 50000 ha) o pequeña
  • Cuenta cuántas áreas hay en cada categoría
  • Calcula la extensión promedio por categoría

Recapitulación

  • select() selecciona columnas por nombre, posición o patrones
  • filter() filtra filas basado en condiciones lógicas
  • mutate() crea o modifica variables
  • summarise() resume datos calculando estadísticas
  • group_by() agrupa datos para resúmenes por grupo
  • arrange() ordena filas por una o más variables
  • Todos los verbos se pueden encadenar con el pipe |>
