Estilo y Theming de Gráficos

Sesión Complementaria

Date

December 31, 2025

Esquema de la sesión

  • Principios fundamentales de comunicación y diseño visual de datos.
  • Anatomía de la función theme() en ggplot2.
  • Uso de temas predefinidos (theme_minimal(), theme_light(), theme_bw()).
  • Personalización de paletas de color para datos cualitativos y cuantitativos.
  • Ajuste de jerarquía tipográfica, títulos, subtítulos, pies de figura y leyendas.
  • Creación de un tema corporativo o personalizado reutilizable.

Objetivo de la sesión

Aprender a pulir la estética visual de las figuras generadas en R para publicación o reportes técnicos, logrando gráficos con alto contraste, legibilidad y coherencia gráfica.

Conexión con el curso

Esta sesión complementaria amplía las capacidades gráficas introducidas en la Sesión 6 y a lo largo de los ejemplos del curso. Una vez que sabemos manipular, unir y filtrar datos con Tidyverse, el toque final para comunicar resultados profesionales reside en la personalización estética de los gráficos.

Datos utilizados

  • data/poblacion_peru.csv: Registro de evolución censal y población departamental.

Práctica guiada

library(tidyverse)
library(janitor)

# Cargar y preparar datos demográficos
poblacion <- read_csv("data/poblacion_peru.csv") |>
  clean_names() |>
  mutate(total = hombres + mujeres)
# 1. Gráfico base sin personalización
p_base <- ggplot(poblacion, aes(x = factor(ano), y = total / 1e6)) +
  geom_col(fill = "#2C3E50", width = 0.6) +
  labs(
    title = "Crecimiento de la Población en el Perú",
    subtitle = "Población total registrada en millones de habitantes",
    x = "Año Censal",
    y = "Millones de habitantes",
    caption = "Fuente: Instituto Nacional de Estadística e Informática (INEI)"
  )

p_base
# 2. Aplicar un tema base y personalizar tipografía y ejes
p_estilizado <- p_base +
  theme_minimal(base_size = 13) +
  theme(
    plot.title = element_text(face = "bold", size = 16, color = "#1a252f", margin = margin(b = 6)),
    plot.subtitle = element_text(color = "#566573", margin = margin(b = 15)),
    plot.caption = element_text(size = 9, color = "#7f8c8d", face = "italic"),
    axis.title.x = element_text(margin = margin(t = 10), face = "bold"),
    axis.title.y = element_text(margin = margin(r = 10), face = "bold"),
    panel.grid.minor = element_blank(),
    panel.grid.major.x = element_blank()
  )

p_estilizado
# 3. Creación de una función de tema propia para reutilizar en todo el proyecto
tema_curso_r <- function(base_size = 12) {
  theme_minimal(base_size = base_size) +
    theme(
      plot.title = element_text(face = "bold", color = "#2C3E50"),
      plot.subtitle = element_text(color = "#7F8C8D"),
      axis.text = element_text(color = "#34495E"),
      panel.grid.minor = element_blank()
    )
}

# Aplicar el tema personalizado
ggplot(poblacion, aes(x = factor(ano), y = total / 1e6)) +
  geom_point(color = "#28A87D", size = 3) +
  geom_line(aes(group = 1), color = "#28A87D", linewidth = 1) +
  labs(title = "Tendencia de Crecimiento", x = "Año", y = "Habitantes (M)") +
  tema_curso_r()

Ejercicios propuestos

  1. Modificar los colores del gráfico de barras utilizando una paleta corporativa de dos tonos.
  2. Mover la leyenda de un gráfico de dispersión a la parte inferior horizontal usando theme(legend.position = "bottom").
  3. Aplicar tu función de tema personalizada a uno de los mapas creados en la Sesión 6.

Resultado esperado

Ser capaz de transformar visualizaciones básicas por defecto en gráficos listos para informes ejecutivos o publicaciones científicas, con identidad visual definida y alta legibilidad.
