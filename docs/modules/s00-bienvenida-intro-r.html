Bienvenida e Introducción a R

Sobre el Curso

Este es un curso introductorio de programación en R con énfasis en el ecosistema Tidyverse y análisis espacial. El curso está diseñado para personas que desean aprender a trabajar con datos de manera ordenada, reproducible y eficiente.

  • Ciencia de datos aplicada
  • Análisis reproducible
  • Ecosistema Tidyverse
  • Análisis espacial con sf

Objetivos del Curso

Al finalizar este curso podrás:

  • ✓ Escribir código R básico de forma legible
  • ✓ Importar datos desde múltiples formatos
  • ✓ Limpiar y transformar datos con dplyr
  • ✓ Organizar datos con tidyr
  • ✓ Trabajar con datos espaciales usando sf
  • ✓ Crear visualizaciones con ggplot2
  • ✓ Integrar análisis espacial con tidyverse
  • ✓ Crear análisis reproducibles

Contenido del Curso

Sesión 1: Fundamentos de R

  • Valores atómicos y tipos de datos
  • Creación de objetos (<-)
  • Operadores básicos
  • Estructuras de datos: vectores, matrices, data frames, listas
  • Funciones en R

Sesión 2: Importar y Revisar Datos

  • Importar desde diferentes formatos (CSV con readr, Excel con readxl, datos espaciales con sf)
  • Revisar estructura de datos
  • Limpiar nombres con janitor
  • Visualizar tipos de datos con visdat
  • El operador pipe |>

Sesión 3: dplyr - Manipulación de Datos

Los verbos principales de dplyr:

  • select(): Seleccionar columnas
  • filter(): Filtrar filas
  • mutate(): Crear/modificar variables
  • summarise(): Resumir datos
  • group_by(): Agrupar datos
  • arrange(): Ordenar datos

Sesión 4: tidyr - Organización de Datos

  • Principios de Tidy Data
  • pivot_longer(): Datos anchos → largos
  • pivot_wider(): Datos largos → anchos
  • separate() y unite(): Dividir y unir columnas
  • Aplicaciones prácticas

Sesión 5: Datos Espaciales con sf

  • ¿Qué son datos espaciales?
  • El paquete sf (Simple Features)
  • Tipos de geometrías (puntos, líneas, polígonos)
  • Lectura/escritura de formatos espaciales
  • Integración con tidyverse
  • Visualización con geom_sf()
  • Operaciones espaciales básicas

Instalación de Software

Programas Necesarios

  1. R (versión 4.5.2 o superior)
    • cran.r-project.org
  2. RStudio (versión 1.1.401 o superior)
    • posit.co/download/rstudio-desktop
  3. Rtools 45 (solo Windows)
    • cran.r-project.org/bin/windows/Rtools

Paquetes Principales

# Tidyverse y manipulación de datos
packages <- c(
  "tidyverse",  # Colección completa
  "janitor",    # Limpieza de nombres
  "here",       # Rutas reproducibles
  "readxl",     # Leer Excel
  "writexl",    # Escribir Excel
  "visdat"      # Visualizar datos
)

install.packages(packages)

Paquetes Espaciales

# Paquetes para datos espaciales
spatial_packages <- c(
  "sf",        # Simple Features (principal)
  "terra",     # Datos ráster
  "mapview",   # Visualización interactiva
  "leaflet",   # Mapas web
  "tmap"       # Mapas temáticos
)

install.packages(spatial_packages)

Paquetes Adicionales

# Paquetes de texto
install.packages("tm")

# stringr.plus (desde GitHub)
install.packages("remotes")
remotes::install_github("johncassil/stringr.plus")

Requisitos Especiales para sf

macOS:

brew install gdal

Linux (Ubuntu/Debian):

sudo apt-get install libudunits2-dev libgdal-dev libgeos-dev libproj-dev

Windows: Rtools 45 ya incluye todo lo necesario ✓

Estrategia de Aprendizaje

  • Practica el código - no solo leas
  • Experimenta - cambia valores y observa qué pasa
  • Comete errores - son parte del aprendizaje
  • Consulta la documentación - usa ?nombre_funcion
  • Busca ayuda - Stack Overflow, comunidad R

Recursos de Ayuda

Preguntas Frecuentes

“Nunca he programado antes, ¿podré seguir el curso?”

¡Sí! Este curso está diseñado para principiantes.

  • Empezamos desde cero
  • Explicamos cada concepto paso a paso
  • Muchos ejemplos prácticos

“¿Necesito conocer estadística?”

No es obligatorio para este curso introductorio.

  • Nos enfocamos en manipulación de datos
  • Conceptos estadísticos básicos se explican cuando aparecen
  • El énfasis está en programación y ciencia de datos

“¿Cuánto tiempo debo dedicar a practicar?”

Recomendación:

  • Durante el curso: Participación activa
  • Después de cada sesión: 1-2 horas practicando
  • Total: Al menos 10-15 horas de práctica adicional
  • ¡Entre más practiques, mejor!

“¿Qué hago si me quedo atascado?”

Estrategias:

  1. Lee el mensaje de error completo
  2. Busca el error en Google
  3. Consulta la documentación (?funcion)
  4. Pregunta en Stack Overflow
  5. Revisa los ejemplos del curso
  6. Contacta al instructor

¿Qué NO cubriremos?

Este es un curso introductorio, NO cubriremos:

  • Modelado estadístico avanzado
  • Machine learning
  • Shiny (aplicaciones web)
  • Análisis de series temporales avanzadas
  • Programación avanzada en R

¡Pero tendrás las bases para aprender todo esto después!
