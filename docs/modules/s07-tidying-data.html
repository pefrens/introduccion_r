Tidy Data (Datos Ordenados)

Definición de Tidy Data

“Los conjuntos de datos ordenados son fáciles de manipular, modelar y visualizar, y tienen una estructura específica: cada variable es una columna, cada observación es una fila y cada tipo de unidad observacional es una tabla.”

Hadley Wickham, Tidy Data

Principios de Tidy Data

Un dataset es “tidy” (ordenado) cuando cumple:

  1. Cada variable es una columna
  2. Cada observación es una fila
  3. Cada valor tiene su propia celda

¿Por qué Tidy Data?

  • Facilita el análisis y visualización: estructura consistente
  • Funciona mejor con tidyverse: todos los verbos de dplyr esperan datos ordenados
  • Simplifica la manipulación: no necesitas pensar en la estructura
  • Permite código más limpio: menos transformaciones intermedias

Datos No Ordenados: Ejemplos

Ejemplo 1: Columnas contienen valores, no variables

# Formato ancho (NO ordenado)
pais      año_2020  año_2021  año_2022
Peru      100       120       140
Chile     150       160       170

Problema: Los años deberían ser valores de una variable, no nombres de columnas.

Datos No Ordenados: Ejemplos

Ejemplo 2: Múltiples variables en una columna

# NO ordenado
departamento    tipo_valor
Cusco           poblacion_300000
Lima            poblacion_9000000
Cusco           area_71986

Problema: tipo_valor contiene dos variables: tipo y valor.

Datos Ordenados: El Mismo Ejemplo

# Formato largo (ordenado)
pais      año    poblacion
Peru      2020   100
Peru      2021   120
Peru      2022   140
Chile     2020   150
Chile     2021   160
Chile     2022   170

Ahora sí: Cada variable en su columna, cada observación en su fila.

pivot_longer() - Pivotear a Más Largo

¿Cuándo usar pivot_longer()?

Usa pivot_longer() cuando:

  • Los nombres de columnas son valores de una variable, no nombres de variables
  • Tienes datos en formato “ancho” que necesitas hacer “largos”
  • Quieres preparar datos para graficar con ggplot2

Ejemplo Básico: De Ancho a Largo

library(tidyr)

# Datos en formato ancho
data_wide <- data.frame(
  pais = c("Peru", "Chile", "Argentina"),
  año_2020 = c(100, 150, 200),
  año_2021 = c(120, 160, 210),
  año_2022 = c(140, 170, 220)
)

data_wide
       pais año_2020 año_2021 año_2022
1      Peru      100      120      140
2     Chile      150      160      170
3 Argentina      200      210      220

Aplicando pivot_longer()

# Convertir a formato largo
data_long <- data_wide |>
  pivot_longer(
    cols = starts_with("año_"),  # columnas a pivotar
    names_to = "año",             # nombre de la nueva columna para los nombres
    values_to = "poblacion"       # nombre de la nueva columna para los valores
  )

data_long
# A tibble: 9 × 3

1 Peru      año_2020       100
2 Peru      año_2021       120
3 Peru      año_2022       140
4 Chile     año_2020       150
5 Chile     año_2021       160
6 Chile     año_2022       170
7 Argentina año_2020       200
8 Argentina año_2021       210
9 Argentina año_2022       220

Sintaxis de pivot_longer()

data |>
  pivot_longer(
    cols = ___________________,    # Columnas a pivotar
    names_to = _______________,    # Nombre de la nueva variable con nombres
    values_to = ______________     # Nombre de la nueva variable con valores
  )

Seleccionando Columnas en pivot_longer()

Diferentes formas de seleccionar columnas:

# Por nombre
cols = c(año_2020, año_2021, año_2022)

# Con helper de select
cols = starts_with("año_")
cols = ends_with("_total")
cols = contains("temp")

# Todas excepto...
cols = -pais
cols = -c(pais, region)

# Por posición
cols = 2:4

Transformar Tipos en pivot_longer()

data_long_corrected <- data_wide |>
  pivot_longer(
    cols = starts_with("año_"),
    names_to = "año",
    values_to = "poblacion",
    names_prefix = "año_",           # Remover prefijo
    names_transform = as.numeric     # Convertir a numérico
  )

Ejemplo Real: Datos de Áreas Naturales

library(vegan)
data("BCI")

# Ver estructura original

BCI tiene especies como columnas (formato ancho).

Pivotear BCI a Formato Largo

# Convertir a tibble y agregar ID de parcela
bci_long <- BCI |>
  as_tibble(rownames = "plot_n") |>
  pivot_longer(
    -plot_n,                    # Todas menos plot_n
    names_to = "especies",
    values_to = "abundancia"
  )

bci_long

Filtrar Valores Cero

# Remover especies con abundancia cero
bci_long_clean <- bci_long |>
  filter(abundancia != 0)

# Comparar tamaños
nrow(bci_long)        # Con ceros
nrow(bci_long_clean)  # Sin ceros

pivot_wider() - Pivotear a Más Ancho

¿Cuándo usar pivot_wider()?

Usa pivot_wider() cuando:

  • Tienes valores en filas que deberían ser columnas
  • Necesitas crear una tabla de resumen
  • Quieres un formato más legible para presentación

De Largo a Ancho: Ejemplo Básico

# Volver de largo a ancho
data_wide_again <- data_long_corrected |>
  pivot_wider(
    names_from = año,           # Columna con nombres
    values_from = poblacion     # Columna con valores
  )

data_wide_again
# A tibble: 3 × 4
  pais      `2020` `2021` `2022`
  <chr>      <dbl>  <dbl>  <dbl>
1 Peru         100    120    140
2 Chile        150    160    170
3 Argentina    200    210    220

Sintaxis de pivot_wider()

data |>
  pivot_wider(
    names_from = _______________,    # Columna con nombres
    values_from = ______________,    # Columna con valores
    values_fill = _______________    # Valor para celdas vacías (opcional)
  )

Rellenar Valores Faltantes

# Con valores NA por defecto
bci_wide <- bci_long_clean |>
  pivot_wider(
    names_from = especies,
    values_from = abundancia
  )

# Rellenar NA con 0
bci_wide_filled <- bci_long_clean |>
  pivot_wider(
    names_from = especies,
    values_from = abundancia,
    values_fill = 0              # Cambiar NA por 0
  )

Ejemplo Práctico: Tabla de Resumen

library(dplyr)

# Crear tabla resumen de áreas por categoría y año
anp_summary <- anp |>
  group_by(categoria, año_creacion) |>
  summarise(n_areas = n()) |>
  pivot_wider(
    names_from = año_creacion,
    values_from = n_areas,
    values_fill = 0

separate() y unite()

separate(): Separar Una Columna

Divide una columna en múltiples columnas.

# Datos con fechas combinadas
data_fechas <- data.frame(
  id = 1:3,
  fecha = c("2021-01-15", "2021-02-20", "2021-03-25")
)

data_fechas
  id      fecha
1  1 2021-01-15
2  2 2021-02-20
3  3 2021-03-25

Aplicando separate()

# Separar fecha en año, mes, día
data_separada <- data_fechas |>
  separate(
    fecha,
    into = c("año", "mes", "dia"),
    sep = "-"
  )

data_separada
  id  año mes dia
1  1 2021  01  15
2  2 2021  02  20
3  3 2021  03  25

separate(): Sintaxis

data |>
  separate(
    col = _______________,          # Columna a separar
    into = c("col1", "col2"),       # Nombres de nuevas columnas
    sep = "___",                    # Separador (regex)
    convert = TRUE                  # Convertir tipos automáticamente
  )

separate_rows(): Separar y Expandir Filas

# Datos con múltiples ubicaciones
data_multi <- data.frame(
  area = c("Manu", "Huascaran"),
  departamentos = c("Cusco y Madre de Dios", "Ancash")
)

data_multi
       area         departamentos
1      Manu Cusco y Madre de Dios
2 Huascaran                Ancash

Aplicando separate_rows()

# Separar departamentos en filas diferentes
data_expandida <- data_multi |>
  separate_rows(departamentos, sep = " y ")

data_expandida
# A tibble: 3 × 2
  area      departamentos
  <chr>     <chr>        
1 Manu      Cusco        
2 Manu      Madre de Dios
3 Huascaran Ancash

unite(): Unir Columnas

Combina múltiples columnas en una.

# Unir año, mes, día de vuelta
data_unida <- data_separada |>
  unite(
    "fecha_completa",
    año, mes, dia,
    sep = "-"
  )

data_unida
  id fecha_completa
1  1     2021-01-15
2  2     2021-02-20
3  3     2021-03-25

unite(): Sintaxis

data |>
  unite(
    "nueva_columna",              # Nombre de la columna resultante
    col1, col2, col3,             # Columnas a unir
    sep = "_",                    # Separador
    remove = TRUE                 # ¿Eliminar columnas originales?
  )

Aplicación Práctica Completa

Caso de Estudio: Áreas Naturales del Perú

Objetivos:

  1. Separar ubicaciones políticas múltiples
  2. Separar fechas de modificación múltiples
  3. Limpiar texto de categorías
  4. Crear un dataset ordenado y listo para análisis

Paso 1: Explorar los Datos

library(readxl)
library(janitor)

anp <- read_excel("data/areas_naturales_peru.xlsx", skip = 1) |>
  clean_names()

# Ver estructura
glimpse(anp)

# Examinar ubicaciones problemáticas
anp |> select(ubicacion_politica) |> head()

Paso 2: Separar Ubicaciones Múltiples

anp_tidy <- anp |>
  separate_rows(
    ubicacion_politica,
    sep = " y |\\, | Y "    # Separadores múltiples
  )

# Verificar
anp_tidy |>
  select(nombre_area, ubicacion_politica) |>
  filter(str_detect(nombre_area, "Manu"))

Paso 3: Separar Fechas Múltiples

anp_tidy <- anp_tidy |>
  separate_rows(
    fecha_promulgacion__modificacion,
    sep = " \\/ |\\;|\\-"
  ) |>
  separate_rows(
    base_legal_modificacion,
    sep = "\\;|\\/|\\,"
  )

Paso 4: Limpiar y Transformar

library(tm)  # Para removePunctuation, removeNumbers
library(stringr.plus)  # Para str_extract_before/after

anp_clean <- anp_tidy |>
  mutate(
    # Limpiar categoría
    categoria = categoria |>
      str_squish() |>
      removeNumbers() |>
      removePunctuation() |>
      str_to_title(),

    # Extraer tipo de documento
    tipo_doc_crea = str_extract_before(base_legal_creacion, "Nº"),
    num_doc_crea = str_extract_after(base_legal_creacion, "Nº"),

    # Limpiar espacios en todas las columnas de texto
    across(where(is.character), str_squish)
  )

Resultado Final: Dataset Ordenado

# Verificar el resultado
glimpse(anp_clean)

# Ahora podemos hacer análisis fácilmente
anp_clean |>
  group_by(ubicacion_politica) |>
  summarise(n_areas = n_distinct(nombre_area)) |>
  arrange(desc(n_areas))

Resumen: ¿Cuándo Pivotear?

Señales de que Necesitas pivot_longer()

  • Los nombres de columnas son valores, no variables
  • Tienes datos en formato “ancho”
  • Ves patrones en nombres de columnas (año_2020, año_2021, etc.)
  • Quieres graficar con ggplot2 y necesitas una variable categórica
  • Necesitas filtrar o agrupar por lo que ahora son columnas

Señales de que Necesitas pivot_wider()

  • Quieres crear una tabla de resumen legible
  • Necesitas comparar valores lado a lado
  • Vas a exportar a Excel para presentación
  • Tienes múltiples observaciones por fila que deberían ser columnas

Ancho vs. Largo: No es Absoluto

Los datasets no son inherentemente “anchos” o “largos”. Son más anchos o más largos dependiendo de:

  • El análisis que quieres hacer
  • La visualización que quieres crear
  • Las operaciones que necesitas realizar

Consejos y Mejores Prácticas

Consejos para Pivotear

  1. Explora primero: Usa head(), glimpse(), names() antes de pivotear
  2. Prueba con subset: Usa slice(1:10) para probar el código con pocos datos
  3. Verifica tipos: Usa names_transform para convertir tipos automáticamente
  4. Maneja NA: Decide si usar values_drop_na o values_fill
  5. Nombra bien: Usa nombres descriptivos para names_to y values_to

Errores Comunes

  1. Olvidar el pipe: Recuerda usar |> o %>%
  2. Tipo de dato incorrecto: Las columnas pivoteadas son siempre character por defecto
  3. Separadores complejos: Usa regex para patrones múltiples
  4. Valores duplicados: pivot_wider() falla si hay duplicados - usa values_fn
  5. Columnas sin nombre: Asegúrate que todas las columnas tengan nombre

Debugging de Pivots

# 1. Ver qué columnas seleccionas
data |>
  select(starts_with("año_")) |>
  names()

# 2. Pivotar subset pequeño
data |>
  slice(1:5) |>
  pivot_longer(...)

# 3. Verificar tipos
data_pivoted |>
  glimpse()

# 4. Buscar duplicados antes de pivot_wider
data |>
  count(id_var, categoria_var) |>
  filter(n > 1)

Recapitulación

Conceptos Clave

  • Tidy data = cada variable es una columna, cada observación es una fila
  • pivot_longer() convierte datos anchos a largos
  • pivot_wider() convierte datos largos a anchos
  • separate() divide una columna en múltiples
  • separate_rows() divide y crea nuevas filas
  • unite() combina múltiples columnas
  • Usa names_transform para convertir tipos de datos
  • Usa values_fill para manejar valores faltantes

Flujo de Trabajo Típico

# Flujo completo de ordenamiento
datos_ordenados <- datos_crudos |>
  # 1. Limpiar nombres
  clean_names() |>
  # 2. Pivotar si es necesario
  pivot_longer(...) |>
  # 3. Separar columnas complejas
  separate_rows(...) |>
  # 4. Limpiar y transformar
  mutate(...) |>
  # 5. Filtrar valores problemáticos
  filter(!is.na(...))
